# Li Auto для Home Assistant — русская версия

Форк [C3H3-AI/ha-lixiang](https://github.com/C3H3-AI/ha-lixiang) (MIT, автор оригинала — C3H3-AI) с русским переводом интерфейса настройки.

## Что добавлено
- `custom_components/lixiang_auto/translations/ru.json` — русский перевод окон входа, ошибок и параметров интеграции.
- Код интеграции не менялся, версия 1.3.1 как в оригинале.

## Важно
- Интеграция принимает только **11-значный номер материкового Китая** (аккаунт Li Auto).
- Вход через интеграцию сбрасывает сессию в приложении Li Auto.
- Проверена на L7 до рестайлинга (в оригинале проверена только L6).
- Если сервер Lixiang недоступен (потери пакетов на маршруте в Китай), все сущности временно становятся `unavailable`.

## Установка через HACS
1. HACS → ⋮ → Custom repositories → `https://github.com/alimp01/ha-lixiang-ru`, категория **Integration**.
2. Скачать «Li Auto», перезапустить Home Assistant.
3. Настройки → Устройства и службы → Добавить интеграцию → Li Auto.
